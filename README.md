เว็บอ่านมังงะออนไลน์ พร้อมระบบ CRUD operations และระบบ Authentication (Admin / Member)
รองรับการเชื่อมต่อกับทั้ง XAMPP (Local MySQL) และ Docker (MariaDB)

-------------------------------------------------------------------------------------------------------------------------
🔌 การเชื่อมต่อฐานข้อมูล (Database Connection: XAMPP & Docker)
-------------------------------------------------------------------------------------------------------------------------

โครงสร้างฐานข้อมูลและไฟล์ `manga_db.sql` ได้รับการปรับปรุงให้รองรับทั้ง XAMPP และ Docker เรียบร้อยแล้ว

**คำสั่งตรวจสอบสถานะการเชื่อมต่อฐานข้อมูล:**
```bash
npm run db:check
```

**คำสั่งสลับฐานข้อมูลใน .env ได้ทันทีด้วยคำสั่งเดียว:**
- สลับไปใช้ **XAMPP** (Port 3306, ไม่มีรหัสผ่าน):
  ```bash
  npm run db:xampp
  ```
- สลับไปใช้ **Docker MariaDB** (Port 3307, rootpassword):
  ```bash
  npm run db:docker
  ```

-------------------------------------------------------------------------------------------------------------------------
🚀 วิธีการรันโปรเจค
-------------------------------------------------------------------------------------------------------------------------

### วิธีที่ 1: รันด้วย Docker (ครบทั้งเว็บ + ฐานข้อมูลในคำสั่งเดียว)
1. เปิด Docker Desktop
2. รันคำสั่ง:
   ```bash
   docker compose up -d --build
   ```
3. เข้าใช้งานผ่านเบราว์เซอร์: `http://localhost:3000`
4. หยุดการทำงาน:
   ```bash
   docker compose down
   ```

### วิธีที่ 2: รันด้วย XAMPP (สำหรับพัฒนาในเครื่อง Local)
1. เปิด XAMPP Control Panel และ Start บริการ **MySQL** (พอร์ต 3306)
2. นำเข้าไฟล์ `manga_db.sql` เข้าสู่ฐานข้อมูลชื่อ `manga_db` (ผ่าน phpMyAdmin หรือ MySQL CLI)
3. ตรวจสอบว่า `.env` ชี้ไปที่ `DATABASE_URL="mysql://root:@127.0.0.1:3306/manga_db"` (หรือรัน `npm run db:xampp`)
4. รันโปรเจค Next.js:
   ```bash
   npm run dev
   # หรือรันผ่าน bash ./run.sh
   ```
5. เข้าใช้งานผ่านเบราว์เซอร์: `http://localhost:3000`

📦 อัพเดทข้อมูลฐานข้อมูลและ Prisma Client
-------------------------------------------------------------------------------------------------------------------------
เมื่อมีการแก้ไข Schema หรือต้องการ Export ฐานข้อมูลล่าสุด:
```bash
# อัพเดท Prisma Client
npm run prisma:generate

# Export ฐานข้อมูลจาก Docker ออกมาเป็น manga_db.sql
docker exec -i manga_db mysqldump -u root -prootpassword manga_db > manga_db.sql
```
