เว็ปขึ้นมังงะ อ่่านมังงะ พร้อมระบบ CRUD operations.--------------------------------------------------------------------------------------------------------------------------
มี DockerFile สำหรับรัน เว็ป + Database เรียบร้อยแล้ว.

วิธีการรันโปรเจคนี้
1. ในเครื่องต้องมี Docker Desktop 
2. เปิด Terminal แล้วเข้าไปที่ folder ที่มีไฟล์ Dockerfile นี้ 
3. พิมพ์
   
```
docker compose up -d --build
```
เข้าเว็ป http://localhost:3000/

4. ถ้าต้องการหยุดการทำงาน พิมพ์

```
docker compose down
```

-------------------------------------------------------------------------------------------------------------------------
ก่อนส่งไฟล์ไปเครื่องอื่นหรือส่งให้คนอื่นทำต่ออย่างลืมใส่คำสั่งเพื่ออัพเดท prisma ในไฟล์ database ให้เป็นปัจจุบันในเเครื่องคุณด้วย

**คำสั่ง อัพเดทข้อมูล database **
```
docker exec -i manga_db mysqldump -u root -prootpassword manga_db > manga_db.sql
```
